# เปิด ISSUE จากแชท

ตัวอย่างสกิลที่ตัดรายละเอียดเฉพาะองค์กรออกแล้ว ปรับชื่อ project, label และรายชื่อคนรับให้ตรงกับทีมของคุณ

## ก่อนเริ่ม

- Token อยู่ในตัวแปรสภาพแวดล้อม `GITLAB_TOKEN` (scope `api`) และ URL ของ GitLab อยู่ใน `GITLAB_URL`
- ห้ามพิมพ์ค่า Token ลงในแชท ใน ISSUE หรือในไฟล์ใดๆ
- ใส่รหัสผ่านใน ISSUE ไม่ได้ ใส่ได้แค่ชื่อบัญชีที่ใช้ล็อกอิน

## ขั้นตอน

1. **ระบุ project** ถ้าไม่ชัดให้ถาม
2. **เช็กข้อมูลให้ครบ** ต้องมี URL หน้าที่เกิดปัญหา (บนเว็บทดสอบ ไม่ใช่เว็บจริงของลูกค้า), บัญชีที่ใช้ล็อกอิน, ข้อมูลที่เกิดเคส (รหัสที่ DEV ใช้ค้นได้) ขาดหลายข้อให้ถามรวมในข้อความเดียว
3. **ตรวจว่าเป็นบั๊กในโค้ดจริงไหม** ถ้าสาเหตุน่าจะเป็นข้อมูลผิด หรือยังไม่แน่ใจ อย่าเปิด ให้บอกเหตุผลและถามผู้ใช้ก่อน
4. **เช็กการ์ดซ้ำ** ค้นการ์ดที่ยังเปิดอยู่ด้วยคำสำคัญ 2-4 คำ (ชื่อหน้า อาการ ข้อความ error) ถ้าเจอที่คล้าย ส่งลิงก์แล้วถามว่าจะคอมเมนต์ในใบเดิมหรือเปิดใบใหม่
5. **หาคนรับ** ดูว่าใครแก้ไฟล์ที่เกี่ยวข้องล่าสุดบน branch ที่รันอยู่ แล้วใส่เป็นผู้รับ ถ้ามีรายชื่อคนที่ assign ได้ ให้เลือกจากรายชื่อนั้นเท่านั้น ไม่แน่ใจให้ถาม ห้ามเดา
6. **แนบรูป** ทุกรูปที่ผู้ใช้ส่งในแชท อัปโหลดแล้วใส่ใต้ขั้นตอนหรือใต้ผลที่ผิดใน body
7. **เขียน body สั้นๆ** 3 หัวข้อเท่านั้น (ดูด้านล่าง) 1 การ์ดต่อ 1 อาการ
8. **ถามก่อนเปิด** ถ้าเป็นอาการที่เพิ่งเจอครั้งแรก แสดงร่างให้ผู้ใช้ดูแล้วรอคำว่าเปิดได้
9. **เปิดการ์ด** แล้วตอบด้วยลิงก์ตรงของ ISSUE กับสรุป 1 บรรทัดว่าเปิดเรื่องอะไร

## รูปแบบ body

```markdown
# รายละเอียด
URL: <URL เว็บทดสอบ>
เข้าระบบด้วย: <ชื่อบัญชี>
ข้อมูลที่เกิดเคส: <รหัสที่ DEV ใช้ค้น>

ขั้นตอน:
1. ...

# ผลที่คาดหวัง
...

# ผลตอนนี้
...
```

- ชื่อการ์ด: `[ชื่อหน้า: ส่วนย่อย] อาการที่ผู้ใช้เห็น` ไม่เกิน 60 ตัวอักษร ไม่เขียนสาเหตุในโค้ด
- ขั้นตอนข้อละ 1 การกระทำ ไม่เกิน 5 ข้อ ใช้คำที่อยู่บนหน้าจอ
- ผลที่คาดหวังกับผลตอนนี้ หัวข้อละ 1 ประโยค พูดถึงสิ่งเดียวกัน
- ไม่ใส่ต้นเหตุ ชื่อไฟล์ โค้ด หรือวิธีแก้

## คำสั่ง API (ตัวอย่าง)

```bash
# ค้นการ์ดซ้ำ
curl -s -H "PRIVATE-TOKEN: $GITLAB_TOKEN" \
  "$GITLAB_URL/api/v4/projects/<project-id>/issues?state=opened&search=<คำสำคัญ>"

# อัปโหลดรูป (ได้ markdown กลับมาไว้วางใน body)
curl -s -H "PRIVATE-TOKEN: $GITLAB_TOKEN" -F "file=@shot.png" \
  "$GITLAB_URL/api/v4/projects/<project-id>/uploads"

# เปิดการ์ด
curl -s -H "PRIVATE-TOKEN: $GITLAB_TOKEN" \
  --data-urlencode "title=<ชื่อการ์ด>" \
  --data-urlencode "description=<body>" \
  --data-urlencode "labels=bug" \
  --data-urlencode "assignee_ids=<user-id>" \
  "$GITLAB_URL/api/v4/projects/<project-id>/issues"
```

ถ้าเครื่องมีสคริปต์ที่ใช้ทำงานนี้อยู่แล้ว ให้ใช้สคริปต์นั้นแทน curl ตรงๆ
