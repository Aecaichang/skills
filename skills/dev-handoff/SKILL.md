# ส่งงานให้ QA

ประหยัด token: ห้ามอ่านไฟล์โค้ด ห้ามรันเทส ห้ามเปิดเบราว์เซอร์ ใช้แค่ 3 คำสั่งนี้

```bash
git log -1 --format='%h %s'
git branch --show-current
git diff --stat HEAD~1
```

ถ้าผู้ใช้ระบุช่วง commit หรือ branch มา ให้ใช้ช่วงนั้นแทน `HEAD~1`
เลขการ์ด: หา `#1234` หรือเลข 3-5 หลักใน commit message หรือชื่อ branch ไม่เจอให้ถาม

## ขั้นที่ 1: ถามครั้งเดียวในข้อความเดียว

```
1. ยังไม่ทำอะไร
2. ใช้ user ไหนเทส
3. เช็คข้อไหนแล้ว: deploy+รีเฟรช / ทำจนจบไม่มี error / ลองกรณีผิด / สิทธิ์ (ตอบ "ครบ" ได้)
4. เลขการ์ด (ถ้าหาจาก git ไม่เจอ)
```

## ขั้นที่ 2: ตอบเป็นคอมเมนต์นี้ ในบล็อกโค้ดให้ก๊อปได้ ไม่ต้องอธิบายเพิ่ม

```
### ส่งให้ QA เทส
commit `<hash>` branch `<branch>`

**แก้อะไร**
- <หน้า/API/ไฟล์ จาก diff --stat ข้อละ 1 อย่าง ไม่เกิน 5 ข้อ>

**ยังไม่ทำ** (ไม่ต้องเปิดการ์ด)
- <คำตอบข้อ 1 หรือ "-">

**เทสด้วย**
- <คำตอบข้อ 2 หรือ "-">

**DEV เช็คเองแล้ว**
- [x] deploy ขึ้นแล้ว รีเฟรชแล้วเห็นของใหม่
- [x] ทำงานหลักจนจบ ไม่มี error ไม่มี API 500
- [x] ลองกรณีผิด (ค่าว่าง ค่าแปลก หน้าไม่มีข้อมูล)
- [ ] เรื่องสิทธิ์ (user ไม่มีสิทธิ์ต้องไม่เห็น)
```

ข้อที่ DEV ไม่ได้เช็คใส่ `[ ]` ข้อที่ไม่เกี่ยวต่อท้ายว่า "(งานนี้ไม่เกี่ยว)"
ปิดท้ายบรรทัดเดียว: "แปะในการ์ด #<เลข> ตอนย้ายไปเลน QA ข้อไหนยัง `[ ]` แนะนำเช็คก่อนส่ง"
ห้ามโพสต์ลงการ์ดเอง
