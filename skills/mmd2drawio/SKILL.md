# mmd2drawio: Mermaid เป็นภาพสวยในคำสั่งเดียว

AI เขียนแค่ Mermaid สั้นๆ แล้วให้ตัวแปลงจัดตำแหน่งและวาดให้ ห้ามให้ AI เขียน SVG หรือ XML ของ draw.io เอง ในการทดลองของผู้เขียน วิธีเขียนเองใช้ token มากกว่าราว 2 เท่าและช้ากว่าราว 11 เท่า

| ได้อะไร | เมื่อไร |
|---|---|
| `<ชื่อ>.html` (ค่าเริ่มต้น) | ส่งคน เปิดดู แนบรายงาน ไฟล์เดียว มีหัวเรื่อง ภาพ และต้นฉบับ Mermaid |
| `<ชื่อ>.svg` (`--svg`) | ฝังในเอกสารอื่น SVG ล้วน |
| `<ชื่อ>.drawio` (`--drawio`) | ต้องการลากแก้เองใน draw.io |
| `<ชื่อ>.png` (`--png`) | ใช้แปะใน Word, Excel หรือสไลด์ |

## ขั้นตอน

1. สรุปข้อสรุปของภาพเป็น 1 ประโยค ใช้เป็นหัวเรื่อง เช่น "7 จาก 12 ข้ออยู่ที่การตั้งค่า" ดีกว่า "แผนภาพการตั้งค่า"
2. เลือกชนิดภาพ (ตารางด้านล่าง) แล้วเขียนไฟล์ `.mmd` เก็บไว้คู่ภาพ รอบแก้ให้แก้ต้นฉบับจุดเดียว
3. รัน

   ```bash
   node bin/mmd2drawio.mjs flow.mmd -o out --title "ข้อสรุปของภาพ" --legend --strict
   ```

4. อ่านผลบนหน้าจอ `✓` สำเร็จ, `!` คือ warning พร้อมวิธีแก้, `✗` คือ Mermaid ผิด แก้ตามข้อความไม่เกิน 2 รอบ ห้ามตัดเนื้อหาเงียบๆ เพื่อให้ผ่าน
5. เปิดดูภาพก่อนส่งให้คนอื่น ตรวจว่า ตาตกที่ข้อสรุปก่อนไหม เนื้อหาครบไหม กรอบและชื่อกลุ่มขึ้นครบไหม

## เลือกชนิดภาพ

| อยากตอบคำถาม | ใช้ |
|---|---|
| ระบบมีส่วนไหนต่อกับอะไร | `flowchart` + `subgraph` |
| งานเดินกี่ขั้น ใครทำ แยกทางไหน | `flowchart` |
| ใครเรียกใคร ตามเวลา | `sequenceDiagram` |
| สถานะเปลี่ยนเมื่อไร | `stateDiagram` |
| ตารางโยงกันยังไง | `erDiagram` |
| คลาสอะไรขึ้นกับอะไร | `classDiagram` |
| เปรียบเทียบตัวเลข | `xychart` (bar/line) |

## ตัวเลือก

| ตัวเลือก | ใช้เมื่อ |
|---|---|
| `--title "ข้อความ"` | หัวเรื่องของหน้า |
| `--legend` | ใส่คำอธิบายสัญลักษณ์ใต้ภาพ |
| `--strict` | มี warning ถือว่าล้มเหลว ใช้กับงานส่งคนอื่น |
| `--split` | ER ใหญ่ แยกเป็นหน้าละกลุ่มตาราง |
| `--square` | การ์ดจตุรัส 1080 x 1080 สำหรับโพสต์ |
| `--svg` / `--html` / `--drawio` / `--png` | เลือกชนิดไฟล์ผลลัพธ์ |
| `-t blue\|neutral` | ชุดสี (blue = ค่าเริ่มต้น, neutral = ส้มกับเทา) |
| `--repo <โฟลเดอร์>` | ตรวจว่าไฟล์และบรรทัดใน `%% src` มีจริง |

## เขียน Mermaid ให้ได้ภาพดี

- เกิน ~9 กล่องใน flowchart ให้แยกเป็นภาพรวมกับภาพรายละเอียด
- กล่องหนึ่งส่งไปทุกกล่องในกลุ่ม ให้ครอบด้วย `subgraph` แล้วลากเส้นเดียวที่กรอบ
- ป้ายในกล่องไม่เกิน 3 บรรทัด คำอธิบายยาวไว้นอกภาพ
- สีเน้นใช้ 1-2 จุด: `classDef focal fill:#3598dc,stroke:#3598dc,color:#ffffff` แล้ว `class <id> focal` และต้องมีคำบอกความหมายของสีนั้น เพื่อให้อ่านได้ตอนพิมพ์ขาวดำ
- ทางปฏิเสธใช้ `style X stroke-dasharray:4 3` จะได้กล่องสีแดงอ่อนขอบประ
- id ของ node และ `subgraph` ใน flowchart ต้องเป็นอังกฤษ ป้ายเป็นไทยได้

## ภาพที่มาจากโค้ดจริง

ไล่โค้ดก่อนวาด ทุกกล่องที่อ้างพฤติกรรมของระบบต้องมีที่มา

```text
flowchart LR
  %% src API: Controllers/LeaveController.cs:120 r24867
  %% route: API -> DB
```

- `%% src <id>: path:บรรทัด [รุ่น]` ใส่ที่มาบนกล่อง ใส่เลขรุ่น (revision หรือ commit) ทุกครั้ง เพราะบรรทัดขยับได้
- `%% route: A -> B -> C` ไฮไลต์เส้นทางที่อยากชี้ เช่น ทางอนุมัติหรือทางล้มเหลว

## ภาพโพสต์: การ์ดไอคอนแบบสถาปัตยกรรม

สำหรับภาพโพสต์โซเชียลที่ต้องการให้คนหยุดอ่าน flowchart ธรรมดาดูแข็ง ใช้ต้นแบบ [templates/arch-icons-square.html](templates/arch-icons-square.html) แทน (เขียน SVG มือ ไม่ผ่านตัวแปลง)

- SVG 1080x1080 พื้นเรียบ การ์ดไอคอนขาวมุมโค้งมีเงา ชื่อหนาใต้การ์ด กลุ่มคือกรอบสีอ่อนมีชื่อมุมซ้ายบน ลูกศรสีน้ำเงินมีป้ายสั้นๆ
- วาดไอคอนเอง ไม่ใช้โลโก้ของบริษัทอื่น
- ตัวอักษรเล็กสุดควรไม่ต่ำกว่า 30 เพราะบนมือถือภาพจะถูกย่อเหลือราว 1 ใน 3 ลองดูภาพชุดตัวอย่างใน `assets/` ของ repo นี้
- ถ่ายเป็น PNG ด้วย Chrome headless แล้วเปิดดูก่อนส่ง

## แก้ปัญหา

| อาการ | ทำ |
|---|---|
| `Cannot find package 'pele'` | รัน `npm install` ในโฟลเดอร์นี้ |
| ฟอนต์ไม่ใช่ Anuphan | ฟอนต์โหลดจาก Google Fonts ต้องออนไลน์ ออฟไลน์จะใช้ฟอนต์สำรอง |
| `✗ Lexical error` | Mermaid ผิด ดูบรรทัดที่ชี้ id ภาษาไทยใช้ได้กับ state และ participant ไม่ได้กับ flowchart |
| `[box-overlap]` `[edge-through-box]` `[label-overflow]` | แก้ตามข้อความหลัง `→ แก้:` |
| `--png` ไม่ทำงาน | ต้องมี Chrome หรือ Chromium ในเครื่อง |
